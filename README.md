# 校见 · 国际学校百科与论坛

## 打开网站

直接双击 `index.html`，会自动进入 `preview.html` 本地预览，无需启动服务器。也可以直接打开 `preview.html`。

开发时运行：

```sh
npm install
npm run dev
```

然后打开终端显示的本地地址。

## 更新本地预览

修改 `src/` 中的源码后运行：

```sh
npm run build
```

这会更新根目录的 `preview.html` 和可部署的 `dist/`。`preview.html` 由构建生成，请勿直接编辑。

## 数据保存

当前为演示版，学校资料和讨论均为示例。收藏、点赞和新增讨论保存在当前浏览器；浏览器禁止本地存储时会提示无法保存。文件预览和开发地址的本地数据相互独立。
